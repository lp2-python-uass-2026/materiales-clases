# Ciclos `while` en Python

El ciclo `while` permite repetir un bloque de instrucciones mientras una condición sea verdadera.

A diferencia del ciclo `for`, que se utiliza cuando se conoce la cantidad de repeticiones, el ciclo `while` es útil cuando no se sabe de antemano cuántas veces deberá ejecutarse el proceso.

### Sintaxis

```python
while <condición lógica>:
  bloque de instrucciones dentro del while
  variar la condición
bloque de instrucciones fuera del while
