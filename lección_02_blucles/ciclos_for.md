# Ciclos FOR
Los ciclos `for` son una estructura de control cíclica que permite iterar sobre objetos de diferente tipo (listas, tuplas, set o conjuntos, diccionarios). En cada paso de la iteración se tiene en cuenta a un único elemento del objeto iterable

## Sintaxis
```python
for elemento in objeto_iterable:
    print(elemento)
bloque de instrucciones fuera del for
```
Un **objeto iterable** en *Python* es cualquier objeto que puede devolver sus elementos de uno en uno, lo que permite recorrerlo dentro de un bucle como for

## Instrucciones para modificar el flujo en FOR:
- **Break**: se utiliza para finalizar el bucle, cuando se cumpla una condición
- **Continue**: salta al siguiente paso de la iteración
