# Lección 01: Condicionales

## Introducción

Los programas no siempre ejecutan las mismas instrucciones. En muchas situaciones es necesario tomar decisiones dependiendo de ciertas condiciones.

Las estructuras condicionales permiten controlar el flujo de ejecución de un programa y elegir qué instrucciones ejecutar según el resultado de una expresión lógica.

---

## Objetivos de aprendizaje

Al finalizar esta lección serás capaz de:

- Comprender el concepto de condición.
- Utilizar operadores de comparación.
- Utilizar operadores lógicos.
- Implementar estructuras `if`.
- Implementar estructuras `if-else`.
- Implementar estructuras `if-elif-else`.
- Resolver problemas sencillos mediante la toma de decisiones.
