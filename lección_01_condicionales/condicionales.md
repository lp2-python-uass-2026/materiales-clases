# Condicionales en Python

## Control de flujo
Instrucciones que se ejecutan al cumplirse una condición.
Dependen de una operación lógica
- Igual == 
- Diferente !=
- Menor < 
- Mayor >
- Menor o igual que <=
- Mayor o igual que >=
## Expresiones condicionales
- is
- and
- or
- not
## Sintaxis
if <condición lógica>:
  print("bloque If")
elif <condición lógica>:
  print("bloque Elif")
else: 
  print("bloque Else")
