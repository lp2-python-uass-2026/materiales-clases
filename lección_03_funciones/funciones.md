# Lección 03 - Funciones en Python

## Introducción

Hasta ahora hemos escrito programas donde las instrucciones se ejecutan una después de otra.

Sin embargo, cuando un programa crece, es común necesitar reutilizar bloques de código. Para evitar repetir instrucciones, Python nos permite crear **funciones**.

Una función es un conjunto de instrucciones agrupadas bajo un nombre que pueden ejecutarse cuando sea necesario.

## ¿Por qué usar funciones?

Las funciones permiten:

- Reutilizar código.
- Evitar repeticiones.
- Organizar mejor los programas.
- Facilitar el mantenimiento del código.
- Mejorar la legibilidad.
